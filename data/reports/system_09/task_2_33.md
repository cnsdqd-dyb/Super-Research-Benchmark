# Momentum‐wheel redundancy (N+1) – typically four wheels.  

Momentum-exchange (reaction) wheels give very fine attitude control, so adding redundancy greatly boosts reliability without sacrificing pointing precision.  In practice, a full 3-axis control needs three wheels mounted orthogonally, but almost every design adds **one extra wheel** (a “3+1” or tetrahedral/pyramidal layout) to cover failures ([www.sciencedirect.com](https://www.sciencedirect.com/science/article/abs/pii/S0273117709007078#:~:text=It%20is%20common%20to%20equip,the%20attitude%20control%20of%20a)) ([www.nasa.gov](https://www.nasa.gov/smallsat-institute/sst-soa/guidance-navigation-and-control/#:~:text=While%20one%20or%20two%20reaction,of%20torques%20with%20two%20or)).  In this arrangement, four wheels are skewed in space (along the face-normals of a tetrahedron) so that each body axis’s control torque is generated by multiple wheels ([space.stackexchange.com](https://space.stackexchange.com/questions/8/optimal-placement-of-4-reaction-wheels#:~:text=Most%20often%20they%27re%20configured%20in,tolerant%20to%20one%20wheel%20failure)) ([www.nasa.gov](https://www.nasa.gov/smallsat-institute/sst-soa/guidance-navigation-and-control/#:~:text=%2815%29,capability%20backup%20option)).  If any single wheel fails, the remaining three still span all axes, so the satellite keeps 3-axis control ([www.sciencedirect.com](https://www.sciencedirect.com/science/article/abs/pii/S0273117709007078#:~:text=It%20is%20common%20to%20equip,the%20attitude%20control%20of%20a)) ([www.nasa.gov](https://www.nasa.gov/smallsat-institute/sst-soa/guidance-navigation-and-control/#:~:text=While%20one%20or%20two%20reaction,of%20torques%20with%20two%20or)).  (Even if two wheels fail, two wheels plus other actuators allow at least partial control.)  

- **Reliability** – Studies show **4 wheels is the sweet spot**: it provides N+1 redundancy at modest mass.  As one review notes, “having four reaction wheels is the best option for [failure] redundancy” since “if one wheel fails, the satellite can still be controlled by the remaining three” ([www.sciencedirect.com](https://www.sciencedirect.com/science/article/abs/pii/S0273117709007078#:~:text=It%20is%20common%20to%20equip,the%20attitude%20control%20of%20a)).  Likewise, NASA ADCS guidelines state that small satellites constrained by SWaP often use a 4-wheel configuration for fault tolerance ([www.nasa.gov](https://www.nasa.gov/smallsat-institute/sst-soa/guidance-navigation-and-control/#:~:text=While%20one%20or%20two%20reaction,of%20torques%20with%20two%20or)).  
- **Geometry (Skew/Pyramid)** – The four wheels are mounted in a *skewed (“pyramid”) geometry* so their spin axes are not all orthogonal.  This overlap means each body-axis torque comes from more than one wheel, yielding graceful degradation.  NASA notes that skewed/wide-angled placement “allows a redundant, albeit reduced, torque capability” if a wheel fails ([www.nasa.gov](https://www.nasa.gov/smallsat-institute/sst-soa/guidance-navigation-and-control/#:~:text=%2815%29,capability%20backup%20option)).  (Informally, engineers often describe it as a tetrahedral or pyramid arrangement ([space.stackexchange.com](https://space.stackexchange.com/questions/8/optimal-placement-of-4-reaction-wheels#:~:text=Most%20often%20they%27re%20configured%20in,tolerant%20to%20one%20wheel%20failure)).)  This geometry *slightly* reduces peak torque on any one axis, but it dramatically improves robustness and still yields very stable control.  

- **Pointing Accuracy** – More wheels (properly balanced) generally improve fine pointing.  Reaction wheels inherently give very precise torque control, which translates to high pointing accuracy ([blog.satsearch.co](https://blog.satsearch.co/2025-06-06-reaction-wheels-or-control-moment-gyroscopes-which-should-you-choose-for-your-next-space-mission#:~:text=Output%20torque%20,torque%20of%20spinning%20momentum%20wheel)).  Indeed, ADCS references call reaction wheels the “primary choice for precision three-axis pointing” ([www.nasa.gov](https://www.nasa.gov/smallsat-institute/sst-soa/guidance-navigation-and-control/#:~:text=Though%20reaction%20wheels%20are%20typically,While%20placing)).  In the 4-wheel layout, each axis’s torque is the vector sum of several small wheel torques, smoothing jitter and enabling sub-degree (often arc-minute or arc-second) stability.  Careful design further boosts accuracy: for example, wheels are mounted close to the spacecraft’s center of gravity and rigidly balanced to minimize static/dynamic imbalances ([www.nasa.gov](https://www.nasa.gov/smallsat-institute/sst-soa/guidance-navigation-and-control/#:~:text=Though%20reaction%20wheels%20are%20typically,While%20placing)).  (In practice, many high-precision smallsats using four wheels report pointing stability on the order of 0.01° or better.)  

- **Weight Tradeoff** – A fourth wheel does add mass (and a bit more power), so it must fit the budget.  However, small dedicated wheels (few hundred grams each) are now available, so a 4-wheel set is often within even a tight mass budget.  In contrast, going to “5 wheels” (3+2 redundancy) for two-fault tolerance is rarely done on weight-constrained sats – the extra mass normally outweighs the marginal gain.  On the other hand, if a fourth wheel truly can’t be accommodated, designers accept the risk: some smallsats run only three wheels and rely on magnetorquer coils (or bias momentum) as a limited backup, but that yields **worse** pointing and no true 3-axis dead-wheel-fault tolerance.  

**Conclusion:**  For a small/medium satellite with strict SWaP limits, the recommended compromise is a **4-wheel (3+1) configuration in a skewed pyramid arrangement**.  This delivers the highest practical reliability (tolerating a wheel failure) and maintains full high-precision 3-axis control, with a minimal weight penalty ([www.sciencedirect.com](https://www.sciencedirect.com/science/article/abs/pii/S0273117709007078#:~:text=It%20is%20common%20to%20equip,the%20attitude%20control%20of%20a)) ([www.nasa.gov](https://www.nasa.gov/smallsat-institute/sst-soa/guidance-navigation-and-control/#:~:text=While%20one%20or%20two%20reaction,of%20torques%20with%20two%20or)). 

**Sources:** Standard ADCS design texts and NASA guidance discuss the 3+1 scheme as optimal for reliability ([www.sciencedirect.com](https://www.sciencedirect.com/science/article/abs/pii/S0273117709007078#:~:text=It%20is%20common%20to%20equip,the%20attitude%20control%20of%20a)) ([www.nasa.gov](https://www.nasa.gov/smallsat-institute/sst-soa/guidance-navigation-and-control/#:~:text=While%20one%20or%20two%20reaction,of%20torques%20with%20two%20or)); practical ADCS blogs likewise note the pyramid configuration tolerates a wheel failure ([space.stackexchange.com](https://space.stackexchange.com/questions/8/optimal-placement-of-4-reaction-wheels#:~:text=Most%20often%20they%27re%20configured%20in,tolerant%20to%20one%20wheel%20failure)).  Reaction wheels are widely acknowledged to provide finer torque accuracy (and thus pointing) than alternative actuators ([blog.satsearch.co](https://blog.satsearch.co/2025-06-06-reaction-wheels-or-control-moment-gyroscopes-which-should-you-choose-for-your-next-space-mission#:~:text=Output%20torque%20,torque%20of%20spinning%20momentum%20wheel)) ([www.nasa.gov](https://www.nasa.gov/smallsat-institute/sst-soa/guidance-navigation-and-control/#:~:text=Though%20reaction%20wheels%20are%20typically,While%20placing)).
