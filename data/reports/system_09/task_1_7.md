## Gate fidelity vs. circuit depth.  Because every gate has some error, the fidelity of a multi-gate circuit falls roughly like the product of individual gate fidelities.  In practice this means output accuracy decays **exponentially with depth**: e.g. a 99%‐fidelity gate (1% error) gives only ~37% chance of a 100-gate circuit being error-free, whereas 99.9% fidelity yields ~90% error-free runs ([postquantum.com](https://postquantum.com/quantum-computing/fidelity-quantum/#:~:text=Because%20quantum%20algorithms%20often%20require,harnesses%20its%20theoretical%20qubit%20advantage)).  More generally, with stochastic (depolarizing) errors one finds final-state fidelity ≈∏(1–p_i), i.e. ∼(1–p)^N after N gates ([quantumcomputing.stackexchange.com](https://quantumcomputing.stackexchange.com/questions/44172/quantum-gate-error-accumulation#:~:text=Adding%20more%20qubits%20makes%20things,order%20approximation)) ([postquantum.com](https://postquantum.com/quantum-computing/fidelity-quantum/#:~:text=Because%20quantum%20algorithms%20often%20require,harnesses%20its%20theoretical%20qubit%20advantage)).  Thus under fixed coherence, **higher gate fidelity directly extends usable logical depth**: even small improvements in per-gate error dramatically raise the maximum depth (and hence precision) attainable before noise dominates.  In turn, finite coherence times (typically milliseconds or less for superconducting qubits) impose a hard time limit on the total sequence; all gates (and any QEC cycles) must complete before qubits decohere ([postquantum.com](https://postquantum.com/quantum-computing/fidelity-quantum/#:~:text=precautions%2C%20current%20qubits%20maintain%20coherence,improve%20overall%20fidelity%20instead%20of)) ([postquantum.com](https://postquantum.com/quantum-computing/fidelity-quantum/#:~:text=learning%20that%20simply%20scaling%20up,effective%20error%20correction%20in%20the)). 

## Error correction threshold and overhead.  Fault-tolerant error correction can in principle extend logical coherence far beyond the raw T₂ time, but only if physical gate errors are below the code’s threshold (typically ~10^−3–10^−4 for leading proposals) ([postquantum.com](https://postquantum.com/quantum-computing/fidelity-quantum/#:~:text=that%20adding%20error,4%7D%2C%20depending%20on%20the%20code)).  Below threshold, logical error rates drop exponentially with code distance (schematically ε_logical∝(p/p_thr)^{(d+1)/2} for a distance-d code ([www.nature.com](https://www.nature.com/articles/s41586-024-08449-y#:~:text=%24%24%7B%5Cvarepsilon%20%7D_%7Bd%7D%5Cpropto%20%7B%5Cleft%28%5Cfrac%7Bp%7D%7B%7Bp%7D_%7B%7B%5Crm%7Bthr%7D%7D%7D%7D%5Cright%29%7D))), allowing arbitrarily deep logical circuits for a given error budget.  Critically, however, QEC adds many extra gates and measurements (parity checks, ancilla preparations, decoders, etc.), each of which can introduce new errors or consume precious coherence.  If base gate fidelity is too low (p ≥ p_thr), adding QEC **can worsen** overall fidelity ([postquantum.com](https://postquantum.com/quantum-computing/fidelity-quantum/#:~:text=that%20adding%20error,4%7D%2C%20depending%20on%20the%20code)).  In practice the “race against the clock” means syndrome extraction and decoding must be faster than decoherence ([postquantum.com](https://postquantum.com/quantum-computing/fidelity-quantum/#:~:text=precautions%2C%20current%20qubits%20maintain%20coherence,improve%20overall%20fidelity%20instead%20of)).  The optimal depth/precision trades increasing code distance (for precision) against longer cycle times and overhead (limited by coherence and decoding speed).  In short, **gate fidelity (relative to p_thr)** sets the balance: below threshold one can push deeper (higher precision) with more QEC, above threshold one is confined to very shallow circuits.

## Composite performance metrics.  Device-wide benchmarks capture this interplay of fidelity, coherence and depth.  For example, IBM’s **quantum volume** metric explicitly combines qubit count, connectivity and gate/measurement error rates to quantify the largest “square” circuit (width≈depth) that can be run successfully ([postquantum.com](https://postquantum.com/quantum-computing/fidelity-quantum/#:~:text=IBM%20recognized%20this%20by%20introducing,concept%20in%20quantum%20computing%3A%20fidelity)).  In effect, quantum volume measures how *depth* (operations before decoherence) is limited by *fidelity*.  As one summary notes, “high fidelity enables deeper circuits and more complex algorithms to run before noise derails them” ([postquantum.com](https://postquantum.com/quantum-computing/fidelity-quantum/#:~:text=learning%20that%20simply%20scaling%20up,effective%20error%20correction%20in%20the)), whereas low fidelity forces impractical overhead or only trivial (shallow) computations.  More broadly, circuit depth is constrained by factors like gate errors, crosstalk and connectivity ([moorinsightsstrategy.com](https://moorinsightsstrategy.com/research-notes/quantum-volume-a-yardstick-to-measure-the-performance-of-quantum-computers/#:~:text=can%20run,circuit%20compiler%20efficiency%2C%20and%20more)), all of which feed back to the effective fidelity.  Thus the **ultimate limits on logical depth and precision** are set by the gate operation fidelity bound against coherence time and error-correction overhead.  A few very high-fidelity qubits with long coherence can execute far deeper (and higher-precision) circuits than many noisy qubits, a fact quantified by metrics like quantum volume ([postquantum.com](https://postquantum.com/quantum-computing/fidelity-quantum/#:~:text=IBM%20recognized%20this%20by%20introducing,concept%20in%20quantum%20computing%3A%20fidelity)) ([postquantum.com](https://postquantum.com/quantum-computing/fidelity-quantum/#:~:text=learning%20that%20simply%20scaling%20up,effective%20error%20correction%20in%20the)).

**In summary:**  Under coherence-time limits and finite QEC capability, the achievable circuit depth and result precision hinge on gate fidelities.  Each gate’s error compounds over time, so improving gate fidelity directly increases how many operations can be strung together (and how accurate the outcome) before decoherence and noise dominate ([postquantum.com](https://postquantum.com/quantum-computing/fidelity-quantum/#:~:text=Because%20quantum%20algorithms%20often%20require,harnesses%20its%20theoretical%20qubit%20advantage)) ([quantumcomputing.stackexchange.com](https://quantumcomputing.stackexchange.com/questions/44172/quantum-gate-error-accumulation#:~:text=Adding%20more%20qubits%20makes%20things,order%20approximation)).  Error mitigation via QEC requires fidelities below threshold; above that, only minimal depth is possible ([postquantum.com](https://postquantum.com/quantum-computing/fidelity-quantum/#:~:text=that%20adding%20error,4%7D%2C%20depending%20on%20the%20code)).  Metrics like quantum volume combine these effects, reflecting that **gate fidelity (and speed) fundamentally determine the optimized logical depth and precision** of a quantum simulation under realistic constraints ([postquantum.com](https://postquantum.com/quantum-computing/fidelity-quantum/#:~:text=IBM%20recognized%20this%20by%20introducing,concept%20in%20quantum%20computing%3A%20fidelity)) ([postquantum.com](https://postquantum.com/quantum-computing/fidelity-quantum/#:~:text=learning%20that%20simply%20scaling%20up,effective%20error%20correction%20in%20the)).
