在 RFM 分层里，决定“这条线到底画在哪儿”——也就是把连续型 R、F、M 值切成 1-5 或 1-3 的离散段——只有三条思路，所有公开做法都是这三种思路的变种，没有第四种。

1. 等距分段（Equal-width）  
   先算出 R、F、M 的理论最大-最小值，然后按“等长区间”一刀切。  
   例：Recency 0-365 天，直接 365÷5≈73 天一段，0-73 天给 5 分，73-146 天给 4 分……  
   优点：简单、可解释；缺点：如果数据严重偏态，会出现“90% 的人挤在 1-2 分”的情况。

2. 等频分段（Equal-frequency / 分位数）——最常用  
   把样本按 R、F、M 各自排序后，按 20%、40%、60%、80% 百分位点切成 5 份（或 25%、75% 切成 3 份）。  
   例：Monetary 列 80% 分位点是 ¥1 203，那么 ≥1 203 的人全部给 5 分；60% 分位点是 ¥512，512-1 203 给 4 分……  
   优点：不管分布多偏，每段人数基本相等，模型稳定；缺点：边界值随样本变化，需要定期回算。

3. 业务规则（Domain-driven cut-off）  
   由运营/财务直接指定“有业务意义的门槛”。  
   例：  
   - Recency：≤30 天=5 分（活跃），31-90 天=4 分，91-180 天=3 分，181-365 天=2 分，>365 天=1 分；  
   - Frequency：≥10 次=5 分，7-9 次=4 分……  
   - Monetary：≥¥10 000=5 分，¥5 000-9 999=4 分……  
   优点：可直接对接 KPI（如 30 天未回购就进入唤醒流程）；缺点：需要行业经验，且当业务门槛与数据分布差异过大时，可能出现某段为空。

落地流程（以 Python 为例）  
```python
# 等频 5 段，scores 越高的分段越“好”
rfm['r_score'] = pd.qcut(rfm['Recency'],  5, labels=[5,4,3,2,1])   # 越小越新
rfm['f_score'] = pd.qcut(rfm['Frequency'], 5, labels=[1,2,3,4,5])
rfm['m_score'] = pd.qcut(rfm['Monetary'],  5, labels=[1,2,3,4,5])
```
如果想用业务规则，把 `pd.qcut` 换成 `pd.cut(bins=[0,30,90,180,365,1e10], labels=[5,4,3,2,1])` 即可。

总结  
“客户等级切分边界”并不是算法自动寻优出来的，而是你先选“等距、等频、业务规则”中的一种，再按上面方法把 R、F、M 分别切成 1-5（或 1-3）分；切完以后，把三段分数拼成 111-555 的代码，再去映射成“Champions／高价值／重点挽留”等业务标签即可。
