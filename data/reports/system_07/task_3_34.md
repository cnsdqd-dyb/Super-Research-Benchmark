Post-digital video collage does not “illustrate” deconstruction; it performs it at the level of the smallest programmable unit – the pixel.  
By treating the pixel matrix as both archive and algorithm, the artist turns every frame into a differential engine whose job is to keep meaning permanently *under erasure*.  
The following five operations show how the supposedly neutral grid of RGB values is forced to become the site where Derrida’s *différance* is literally calculated.

1. Matrix = Manuscript  
   The 2-D array is no longer a transparent window but a palimpsest.  
   - Each pixel stores a *trace* of every previous state (motion vectors, compression artefacts, ghost frames).  
   - Because the trace is always *there* and always *partial*, presence and absence coexist in the same location – the technical realisation of Derrida’s “supplement”.

2. Cut/Copy/Paste as *Différance*  
   The clipboard command becomes the digital equivalent of *gramme*:  
   - “Cut” = *différer* (to postpone) – the pixel block is removed but kept in memory, ready to re-appear elsewhere.  
   - “Paste” = *différer* (to differ) – the block is re-inscribed in a new syntagmatic chain, producing semantic slippage.  
   - The operation is recursive: every paste re-writes the source, so the “original” is never recoverable – a perfect performance of iterability.

3. Compression Artefacts as *Parergon*  
   Block-based codecs (H.264, AV1) create their own ornamental frame: macro-block edges, ringing, mosquito noise.  
   These *parerga* are neither inside nor outside the image; they are the economic necessity (bandwidth) made visible.  
   By *amplifying* instead of suppressing them (e.g., quantising matrices pushed to extremes), the artist lets the conditions of transmission become the aesthetic object – deconstruction’s eternal question “what is outside the text?” is answered: the outside is *inside* the pixel.

4. Semantic Drift via Eigenface-Clusters  
   A face-detection CNN exports every 16×16 patch to a 512-D vector.  
   - K-means clustering finds the *average* face-patch.  
   - The video is re-rendered by replacing each patch with its *second*-nearest neighbour, not the first.  
   The result is an uncanny valley where identity is almost itself but never coincides – a computational version of Husserl’s “unfulfilled intention”.

5. Real-time *Erasure* Buffer  
   A shader keeps the last 256 frames in GPU memory.  
   - Every new frame is XOR-ed with the 128-frame-old version.  
   - Where values cancel to zero the pixel becomes transparent, letting through a *third* layer (a live webcam feed).  
   The image is therefore never present *as* image; it is the *difference* between two pasts, perforated by a present that the spectator herself supplies.  
   The spectator becomes the *supplement* that completes (and destabilises) the work.

Outcome  
The pixel matrix is revealed as a *writing machine* that continuously produces and erases its own origin. Instead of collapsing into noise, the work keeps the oscillation *visible*: every frame is a *trace* of a trace, every cut is a citation, every compression artefact is a *parergon* that frames the framing device.  
In this sense post-digital collage does not *represent* deconstruction; it *is* deconstruction executed 60 times per second.
