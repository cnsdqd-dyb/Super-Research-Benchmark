**Destination cognition, often termed "destination image" in tourism literature, refers to tourists' overall mental representations, beliefs, knowledge, and feelings about a place. It forms dynamically through interactions between virtual previews (e.g., VR tours, 360° videos, online content) and on-site visits across pre-, during-, and post-visit stages.[[1]](https://www.mdpi.com/2071-1050/14/1/467)[[2]](https://www.sciencedirect.com/science/article/pii/S2590123024018930)[[3]](https://www.emerald.com/ijchm/article/36/11/3607/1219717/Impact-of-virtual-reality-experiences-on)**

### Key Stages and Interaction Process
Research draws on models like Baloglu and McCleary's (1999) image formation framework (cognitive from info/stimuli, affective from emotions) and holistic models integrating cognitive, affective, and conative (behavioral intention) components.[[1]](https://www.mdpi.com/2071-1050/14/1/467)

1. **Pre-Visit Stage (Virtual Previews' Primary Role)**:
   - Virtual tools like VR/360° tours generate an initial image via **telepresence** (feeling "there") and **sense of presence**, fostering cognitive knowledge (e.g., attributes like scenery), affective responses (e.g., excitement), and conative urges (e.g., visit intent).[[1]](https://www.mdpi.com/2071-1050/14/1/467)[[3]](https://www.emerald.com/ijchm/article/36/11/3607/1219717/Impact-of-virtual-reality-experiences-on)
   - Tourist involvement (personal interest) drives this: higher involvement strengthens all components, moderated by presence—"a strong sense of presence... contributes to the formation of a fantastic holistic image."[[1]](https://www.mdpi.com/2071-1050/14/1/467)
   - Process: Stimuli → Mental imagery/presence → Pre-visit image/expectations → Travel intention (e.g., VR experience explains 70%+ variance in image/intent).[[2]](https://www.sciencedirect.com/science/article/pii/S2590123024018930)[[3]](https://www.emerald.com/ijchm/article/36/11/3607/1219717/Impact-of-virtual-reality-experiences-on)

2. **During-Visit Stage (On-Site Interaction and Modification)**:
   - Actual visits interact with pre-formed expectations via **expectation-disconfirmation theory**: Virtual image sets a baseline; on-site sensory/emotional experiences (sights, interactions) confirm, adjust, or contradict it, refining cognition.
   - Virtual previews reduce uncertainty ("overview of the destination") but coexist with on-site for fuller immersion—"on-site and virtual tourism are expected to exist simultaneously."[[1]](https://www.mdpi.com/2071-1050/14/1/467)
   - Moderators like familiarity or VR sickness influence carryover; e.g., low sickness enhances positive transfer to on-site appeal.[[3]](https://www.emerald.com/ijchm/article/36/11/3607/1219717/Impact-of-virtual-reality-experiences-on)

3. **Post-Visit Stage (Holistic Consolidation)**:
   - Integrates both: Pre-visit virtual shapes entry image; on-site updates to a "more intricate" holistic one, influencing loyalty/WOM.[[1]](https://www.mdpi.com/2071-1050/14/1/467)
   - Parallel model: Cognitive/affective/conative → Holistic image (R²=0.72), with presence amplifying links.[[1]](https://www.mdpi.com/2071-1050/14/1/467)

### Visual Model Summary
```
Virtual Previews (VR/Tours) → Presence/Imagery → Pre-Visit Image (Expectations)
          ↓ (Sets baseline)
On-Site Visits → Experiences (Confirm/Disconfirm) → During-Visit Refinement
          ↓ (Integration)
Post-Visit Holistic Cognition → Intentions/Loyalty
```

Virtual previews prime cognition but gain depth/reality from on-site, creating a synergistic loop—VR boosts intent by 30-70% via image, motivating physical visits that loop back to refine virtual perceptions.[[2]](https://www.sciencedirect.com/science/article/pii/S2590123024018930)[[3]](https://www.emerald.com/ijchm/article/36/11/3607/1219717/Impact-of-virtual-reality-experiences-on) This holds post-pandemic, blending virtual as "try-before-buy" with tangible visits.[[1]](https://www.mdpi.com/2071-1050/14/1/467)
