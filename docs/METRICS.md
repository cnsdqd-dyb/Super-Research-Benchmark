# Evaluation dimensions

SuperResearch reports five dimensions separately: Coverage, Conditional Depth, Utility, Consistency and Objectivity.

| Dimension | Meaning |
|---|---|
| Coverage | Support for the task's reference knowledge nodes in the report. |
| Conditional Depth | Semantic advancement of displayed arguments, assessed with their explicit premises and inference validity. |
| Utility | Usefulness and actionable completeness of the research report under the task requirements. |
| Consistency | Support along reference reasoning paths. |
| Objectivity | Agreement of assessed claims with the task's reference evidence. |

Conditional Depth retains advancement level A (0–3), inference status V and premise-support status S. Its display score is 100A/3 when V is valid, zero when invalid or insufficient, and null when undetermined. A, V and S remain available alongside the score. Repeated conclusions are merged; missing values are kept as missing.

Results show all five dimensions. Consistency is a separate diagnostic and is excluded from the default aggregate. An aggregate, when configured, must record its included dimensions, weights and protocol version. Per-item judgments retain supporting quotations, reference version, report hash and evaluator configuration.
